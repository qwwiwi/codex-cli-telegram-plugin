# v0.4.0 · 2026-11-27

## English

- On Linux, full access lets the agent work anywhere its dedicated system user has access. Run `./install.sh --hooks` as that user, review and run the printed `sudo install …` line, then rerun the installer and check `/doctor`. The bridge grants full access only after the system-wide managed hooks pass its checks. The hooks protect Codex home instruction files, including `AGENTS.md`.
- Brain remembers facts and open tasks from the owner's private chat. Start with `/memory`. Forwarded and foreign input stays separate from owner memory. PreCompact saves a handoff before Codex shortens the conversation, and the SessionStart context has a limit.
- Telegram sends recheck an extended rate-limit cooldown. Reply splitting preserves chunk boundaries, and saved replies are migrated safely before retry. [Issue #4](https://github.com/qwwiwi/codex-cli-telegram-plugin/issues/4) · [Issue #7](https://github.com/qwwiwi/codex-cli-telegram-plugin/issues/7)
- `/usage` shows token trends for 1, 7 or 30 days. Brain leads by default. On a fresh install with Brain off, the local backend defaults to native Codex memories when the setting is unset. Explicit settings and `--no-memories` are honored. [Usage analytics](../usage-analytics.md) · [Native memory settings](../../plugin/docs/install.md#native-codex-memories)

## Русский

- В Linux полный доступ позволяет агенту работать везде, куда имеет доступ его отдельный системный пользователь. Запустите `./install.sh --hooks` от этого пользователя, проверьте и выполните выведенную строку `sudo install …`, повторите установку и откройте `/doctor`. Полный доступ включается после проверки системных хуков, которые защищают инструкции Codex, включая `AGENTS.md`.
- Brain запоминает факты и открытые задачи из личного чата владельца. Начните с `/memory`. Пересылки и чужие сообщения изолированы от памяти владельца. PreCompact сохраняет краткое состояние перед сжатием, а объём контекста при запуске сессии ограничен.
- Отправка в Telegram учитывает продление паузы после ограничения частоты. Длинные ответы делятся по безопасным границам, а сохранённая очередь обновляется перед повторной отправкой. [Issue #4](https://github.com/qwwiwi/codex-cli-telegram-plugin/issues/4) · [Issue #7](https://github.com/qwwiwi/codex-cli-telegram-plugin/issues/7)
- `/usage` показывает расход за 1, 7 или 30 дней. По умолчанию памятью управляет Brain. При новой установке с выключенным Brain локальный Codex включает встроенную память, если выбор не задан явно и не указан `--no-memories`. [Статистика](../usage-analytics.md) · [Настройки встроенной памяти](../../plugin/docs/install.md#native-codex-memories)
